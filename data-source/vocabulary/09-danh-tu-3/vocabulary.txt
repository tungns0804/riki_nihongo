# N3 JUNBI — 文字語彙 · Danh từ 3
# Nguồn: 第5課 (81–100) và 第6課 (101–120)

# ── 第5課：81〜100 ─────────────────────────────────────────────
81. 缶 (かん) = Lon, hộp
・ビール缶を捨てる。
合: 缶詰 (かんづめ)
関: ビン・ペットボトル

82. 画面 (がめん) = Màn hình
・パソコンの画面をずっと見ていると、目が疲れる。
・スマホの画面
・テレビの画面

83. 番組 (ばんぐみ) = Chương trình tivi
・テレビの番組を見る。
・新聞の番組欄
合: ニュース番組・音楽番組 (おんがくばんぐみ)

84. 記事 (きじ) = Bài báo
・この記事によると、日本に住む外国人が増えているそうだ。
合: 新聞記事 (しんぶんきじ)

85. 近所 (きんじょ) = Hàng xóm/ Gần
・近所迷惑
・近所の人とは仲良くしたほうがいい。
・私はよく近所の公園を散歩する。
使い分け: 近所 = nhà ở gần, có quan hệ với mình → 私の家の近所 ○ / マーケットの近所 ✕
使い分け: 近く = chỗ gần, dùng cho mọi thứ → 学校の近くで遊ぶ・近くの山
使い分け: 付近 (ふきん) = khu vực gần, phạm vi rộng (N2) → 東京付近の水族館 ○ / 私の付近で遊ぶ子供 ✕

86. 警察 (けいさつ) = Cảnh sát
・財布を拾ったので、警察に届けた。
合: 警察官 (けいさつかん)・警察署 (けいさつしょ)
関: 交番 (こうばん)

87. 犯人 (はんにん) = Hung thủ, tội phạm
・事件の犯人を捕まえる。

88. 小銭 (こぜに) = Tiền lẻ
・バスに乗ってから小銭がないことに気がつき、とても困った。
関: 〜円玉 (えんだま)・（お）札 (さつ)
使い分け: 細かいお金 = văn nói; 小銭 = cách nói cứng hơn; お釣り (おつり) = tiền thối

89. ごちそう = Đồ thiết đãi
・家族みんなでごちそうを食べて、祖父の誕生日を祝った。
・チンさんは私たちに手作りのギョーザをごちそうしてくれた。
・昨日は先輩にごちそうになった。

90. 作者 (さくしゃ) = Tác giả
・{小説／詩／絵／彫刻}…の作者
・「ハムレット」の作者はシェイクスピアです。
使い分け: 作者 = kịch bản, điêu khắc, hội hoạ (脚本・彫刻・絵画)
使い分け: 著者 (ちょしゃ) = văn bản học thuật, sách hướng dẫn (学術書・案内書)
使い分け: 筆者 (ひっしゃ) = nội dung báo, tạp chí (新聞・雑誌の文章)

91. 作品 (さくひん) = Tác phẩm
・学生の作品をロビーに展示する。
合: 文学作品 (ぶんがくさくひん)・芸術作品 (げいじゅつさくひん)

92. 制服 (せいふく) = Đồng phục
・日本の中学校には制服のある学校が多い。
・制服（会社、学校）
・ユニフォーム（スポーツ）
対: 私服 (しふく) OK の会社
使い分け: 制服 = công ty, trường học; ユニフォーム = thể thao

93. 洗剤 (せんざい) = Chất tẩy rửa
・洗剤で食器を洗う。
合: 食器用洗剤 (しょっきようせんざい)

94. 底 (そこ) = Đế, đáy
・靴の底に穴が空く。
・箱の底が抜ける。
・コップの底
・海の底に潜る。
・あの人は心の底では何を考えているかわからない。

95. 地下 (ちか) = Dưới đất
・大都市は地下の開発が進んでいる。
合: 地下鉄 (ちかてつ)
対: 地上 (ちじょう)

96. 寺 (てら) = Chùa
・お寺に｛まいる／おまいりする｝。
連: お寺参り (おてらまいり)

97. 高速道路 (こうそくどうろ) = Đường cao tốc
・うちの前を高速道路が走っている。
使い分け: 道路 (どうろ) = đường cho xe to, ô tô qua lại → 高速道路
使い分け: 道 (みち) = đường nói chung, đi bộ được → 道を歩く

98. 坂 (さか) = Con dốc
・坂を上る。
連: 急な坂 ＞＜ 緩やかな坂

99. 煙 (けむり) = Khói
・「火事のときは、煙に注意して逃げてください」。
・タバコの煙は体に悪い。

100. 灰 (はい) = Tro, tàn
・タバコの灰
合: 携帯灰皿 (けいたいはいざら)

# ── 第6課：101〜120 ────────────────────────────────────────────
101. 判 (はん) = Con dấu
・書類に判を押す。
合: 判子を押す (はんこをおす) = Đóng dấu
類: 判子 (はんこ)・印 (いん)・印鑑 (いんかん)

102. 名刺 (めいし) = Danh thiếp
・名刺を交換する ≒ やりとりする。
・パーティーで会った人に名刺を配る。
連: 名刺を配る = Đưa danh thiếp

103. 免許 (めんきょ) = Giấy phép
・レストランを開くには、調理師（の）免許が必要だ。
連: 運転免許をとる = Lấy bằng, giấy phép
連: 免許を与える = Trao bằng, giấy phép

104. 多く (おおく) = Nhiều
・オリンピックには多くの国が参加した。

105. 前半 (ぜんはん) = Nửa trước
・映画の前半は退屈だったが、後半はおもしろかった。
対: 後半 (こうはん)

106. 後半 (こうはん) = Nửa sau
・映画の前半は退屈だったが、後半はおもしろかった。
対: 前半 (ぜんはん)

107. 最高 (さいこう) = Cao nhất/ Tuyệt nhất/ Rất
・この店はきのう、開店以来最高の売上を記録した。
・宝くじに当たって、最高の気分だ。
・昨日食べたからあげは最高だった。
・この映画は最高におもしろい。
合: 最高気温 (さいこうきおん)
対: 最低 (さいてい)

108. 最低 (さいてい) = Thấp nhất/ Tệ nhất
・クラスで最低点をとってしまった。
・昨日の映画は最低だった。
・弱いものいじめをするなんて最低だ！最低の人だ。
合: 最低点 (さいていてん)
連: 人が最低 = Con người tệ
対: 最高 (さいこう)

109. 最初 (さいしょ) = Đầu tiên
・最初にひらがなを、次にカタカナを勉強しました。
・ベトナムに来たばかりのころ、最初は右も左もわからなかった。
対: 最後 (さいご)

110. 最後 (さいご) = Cuối cùng
・あとから来た人は列の最後に並んでください。
・最後の出勤日に花束をもらった。
対: 最初 (さいしょ)

111. 自動 (じどう) = Tự động
・このドアは自動だから、手であけなくてもいいです。
合: 自動販売機 (じどうはんばいき) ≒ 自販機 (じはんき)
合: 全自動洗濯機 (ぜんじどうせんたくき)
対: 手動 (しゅどう) = Thủ công

112. 種類 (しゅるい) = Chủng loại
・形容詞は2種類ある。

113. 性格 (せいかく) = Tính cách
・あの人は性格がいいので、みんなに好かれている。
使い方: Chỉ dùng cho người → 明るい性格・まじめな性格・おとなしい性格・積極的な性格

114. 性質 (せいしつ) = Tính chất/ Tính cách
・この布は燃えにくい性質を持っている。
・羊はおとなしい性質の動物だ。
・人は持って生まれた性質をなかなか変えられない。
使い方: 性格 = chỉ dùng cho người; 性質 = dùng cho người, động vật và cả đồ vật

115. 順番 (じゅんばん) = Thứ tự, lần lượt
・じゃんけんで、発表の順番を決めましょう。
・大きい商品から順番に並べる。
・順番を待ってください。

116. 番 (ばん) = Lượt
・次は私の番だ。
・席を離れた人の荷物番をする。
・隣の人に留守番を頼む。
連: 番をする = Giữ chỗ / Trông chừng
合: 留守番 (るすばん)

117. 方法 (ほうほう) = Phương pháp, cách
・いい方法を探す。
・色々な方法を試す。
・新しい方法でやってみる。

118. 製品 (せいひん) = Sản phẩm, đồ, hàng
・日本製・プラスチック製
合: 電気製品 (でんきせいひん)・家電製品 (かでんせいひん)・プラスチック製品

119. 値上がり (ねあがり) = Sự tăng giá
・食品の値上がり
・石油が値上がりする ≒ 値段が上がる。

120. 生 (なま) = Tươi sống
・生の魚
・魚を生で食べられますか。
合: 生野菜 (なまやさい) = Rau sống
合: 生魚 (なまざかな) = Cá tươi, cá gỏi
合: 生肉 (なまにく) = Thịt sống
合: 生物 (なまもの) = Đồ sống, đồ tươi
合: 生ビール = Bia hơi
合: 生ゴミ = Rác nhà bếp, rác tươi
