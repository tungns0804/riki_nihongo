## 121–130
121. 渇く (かわく) = KHÁT ; Khát, khát nước
・のどが[渇いた]。

122. かぐ = Ngửi, hít
・匂いを[かぐ]。

123. 叩く (たたく) = KHẤU ; Đánh, vỗ, gõ, tét
・子供のお尻を[叩く]。
・隣の人の肩を[叩く]。
・ドアを[叩く]。
・スピーチが終わったので、手を[叩いた]。（＝拍手）

124. 殴る (なぐる) = ẨU ; Đánh
・教師が生徒を[殴って]、問題になっている。

125. ける = Đá
・ボールを[ける]。
・彼は怒ると殴ったり、[けったり]する。

126. 抱く (だく) = BÃO ; Ôm
・子供を両手でしっかりと[抱く]。
・恋人の肩を[抱く]。

127. (が)倒れる (たおれる) = ĐẢO ; Đổ/ Ngất, bất tỉnh/ Đổ bệnh
・台風で木が[倒れた]。
・[倒れて]いる人を助けた。
・父は働きすぎて[倒れて]しまった。

128. (を)倒す (たおす) = ĐẢO ; Làm đổ, đánh đổ/ Đánh bại, chinh phục
・花びんを[倒して]割ってしまった。
・ボクシングでチャンピオンを[倒した]。

129. (が)起きる/起こる (おきる/おこる) = KHỞI ; Thức dậy/ Thức/ Xảy ra
・今日は8時に[起きた]。
・父は毎晩遅くまで[起きて]いるようだ。
・最近なかなかやる気が[起きない]・[起こらない]。

130. (を)起こす (おこす) = KHỞI ; Đánh thức/ Dựng lên/ Gây ra, làm
# Sách tô đỏ 起きない ở câu dưới, nhưng từ của mục này là 起こす nên đánh dấu 起こして.
・うちの子は朝[起こして]もなかなか起きない。
・倒れていた自転車を[起こした]。
・事故・事件・問題・裁判(N2)…を[起こす]。

## 131–140
131. 尋ねる (たずねる) = TẦM ; Hỏi
・「ちょっと[お尋ねしたい]のですが…」
・交番で警官に市役所までの道を[尋ねた]。

132. 呼ぶ (よぶ) = HÔ ; Gọi/ Thu hút
# 意味① Gọi: sáu câu đầu. 意味② Thu hút: câu cuối và dòng 連.
・「名前を[呼ばれ]たら返事してください。」
・Grabでタクシーを[呼ぶ]。
・電話で救急車を[呼ぶ]。
・アインさん、ちょっとシンさんを[呼んで]くれませんか。
・私は彼女を「アインちゃん」と[呼んで]いる。
・ホーチミン市は昔サイゴンと[呼ばれていた]。
・ここのタピオカは多くの人から人気を[呼んで]いる。
連: 人気・話題・議論を呼ぶ

133. 叫ぶ声 (さけぶこえ) = KHIẾU THANH ; Tiếng hét
・道を歩いていたら、「助けてー」と[叫ぶ声]が聞こえた。

134. 黙る (だまる) = MẶC ; Im lặng
・先生が質問したが、誰も答えないで[黙って]いる。
・「うるさい。[黙れ]！」
・授業中[黙って]教室を出てはいけない。

135. 飼う (かう) = TỰ ; Nuôi
・何かペットを[飼いたい]と思っている。

136. 数える (かぞえる) = SỐ ; Đếm, tính
・数を[数える]。
・「椅子がいくつか、[数えて]ください。」
・この寺は、日本で最も古い寺の一つに[数えられて]いる。

137. (が)乾く (かわく) = CAN ; Khô
・風が強かったので、外に干した洗濯物はすぐ[乾いた]。
・[乾いた]タオルで体をふいた。
・空気・インクが[乾く]。

138. (を)乾かす (かわかす) = CAN ; Làm khô
・ドライヤーでぬれた髪を[乾かした]。

139. 畳む (たたむ) = ĐIỆP ; Gấp, xếp
・洗濯物を[畳む]。
・傘を[畳んで]バッグに入れる。
合: 折り畳み傘 (おりたたみがさ) = Ô gấp

140. 誘う (さそう) = DỤ ; Mời
・友達を[誘って]映画を見に行った。
・今度、彼女を食事に[誘おう]と思う。
連: 誘いを受ける ＞＜ 誘いを断る (ことわる) = Nhận lời mời ＞＜ Từ chối lời mời
