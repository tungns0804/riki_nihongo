## 01–10
01. 男性 (だんせい) = NAM TÍNH ; Nam giới
・理想の男性と結婚する。

02. 女性 (じょせい) = NỮ TÍNH ; Nữ giới
・あの女性／女の人は誰ですか。

03. 高齢 (こうれい) = CAO LINH ; Già, cao tuổi
・祖母は高齢だがまだとても元気だ。
合: 高齢者 (こうれいしゃ)・高齢化社会 (こうれいかしゃかい)

04. 年上 (としうえ) = NIÊN THƯỢNG ; Hơn tuổi
・年上の友達
・彼女は彼より10年上だ。
対: 年下 (としした)

05. 目上 (めうえ) = MỤC THƯỢNG ; Người trên
・目上の人には敬語で話した方がいい。
対: 目下 (めした)

06. 先輩 (せんぱい) = TIÊN BỐI ; Tiền bối
・モンさんとアインさんは同じ年だが、職場ではアインさんの方が先輩だ。
対: 後輩 (こうはい)

07. 後輩 (こうはい) = HẬU BỐI ; Hậu bối
・モンさんとアインさんは同じ年だが、職場ではアインさんの方が後輩だ。
対: 先輩 (せんぱい)

08. 上司 (じょうし) = THƯỢNG TY ; Sếp, cấp trên
・上司に相談してから決定する。
対: 部下 (ぶか)
関: 同僚 (どうりょう)

09. 相手 (あいて) = TƯƠNG THỦ ; Đối phương, đối thủ
・相手の目を見て話す。→ 話し相手
・今度の試合の相手は強そうだ。
合: 相談相手 (そうだんあいて)・結婚相手 (けっこんあいて)

10. 知り合い (しりあい) = TRI HỢP ; Người quen
・知り合いに息子の就職を頼む。
使い分け: 知り合い = văn nói; 知人 (ちじん) = văn viết

## 11–20
11. 友人 (ゆうじん) = HỮU NHÂN ; Bạn bè
・A:「しんさんを知っていますか。」 B:「ええ、学生時代の友人です。」

12. 仲 (なか) = TRỌNG ; Mối quan hệ
・私はアインさんと仲がいい ＞＜ 仲が悪い
合: 仲間 (なかま) = người cùng làm một việc → 勉強仲間・飲み仲間

13. 生年月日 (せいねんがっぴ) = SINH NIÊN NGUYỆT NHẬT ; Ngày tháng năm sinh
・書類に生年月日を記入する。
関: 誕生日 (たんじょうび)

14. 誕生 (たんじょう) = ĐẢN SINH ; Sự ra đời, sinh ra
・新しい命の誕生を祈る。
・新政権が誕生する。

15. 年 (とし) = NIÊN ; Năm, tuổi
・年の初めに1年の計画を立てる。
・アイン先生は年より若く見えますね！ ＞＜ 年より老けて見える
使い分け: 年 = cảm giác già đi, dùng khi nói; 年齢 (ねんれい) = văn viết và văn nói lịch sự

16. 出身 (しゅっしん) = XUẤT THÂN ; Xuất thân, quê quán
・A:「ご出身はどちらですか。」 B:「日本です。」
・私は大阪大学の出身です。
使い分け: 出身 → hỏi どこ ○, đi với 帰る ✕ ; 故郷・ふるさと → hỏi どこ ✕, đi với 帰る ○

17. 故郷 (こきょう) = CỐ HƯƠNG ; Quê hương
・仕事が忙しくて、もう何年も故郷に帰っていない。
使い分け: 出身 dùng trong hội thoại; 故郷・ふるさと hầu như không dùng trong hội thoại

18. 成長 (せいちょう) = THÀNH TRƯỞNG ; Trưởng thành, tăng trưởng
・子供の成長を喜ぶ。
・事業の成長
・経済成長

19. 成人 (せいじん) = THÀNH NHÂN ; Người lớn, người trưởng thành
・成人式
対: 未成年 (みせいねん)

20. 合格 (ごうかく) = HỢP CÁCH ; Thi đỗ, đỗ
・大学／入学試験／検査に合格する。
対: 不合格 (ふごうかく)

## 21–30
21. 進学 (しんがく) = TIẾN HỌC ; Học lên
・子供の進学について考える。

22. 退学 (たいがく) = THOÁI HỌC ; Nghỉ học, thôi học
・退学の理由を説明する。
合: 退学届 (たいがくとどけ)

23. 就職 (しゅうしょく) = TỰU CHỨC ; Xin việc
・旅行会社に就職する。
合: 就職活動 (しゅうしょくかつどう)

24. 退職 (たいしょく) = THOÁI CHỨC ; Nghỉ việc
・母の介護のため、退職を決めた。
・長年勤めた会社を退職した。
使い分け: 退職 = nghỉ việc (nhân viên bình thường); 辞職 (じしょく) = từ chức (người có chức quyền)

25. 失業 (しつぎょう) = THẤT NGHIỆP ; Thất nghiệp
・会社が倒産して、失業した。
合: 失業者 (しつぎょうしゃ)
使い分け: Hỏi「今何されてますか」→「今失業してます」△ ; 「今就職活動中です」○

26. 残業 (ざんぎょう) = TÀN NGHIỆP ; Làm thêm giờ
・残業が多くて、疲れた。

27. 生活 (せいかつ) = SINH HOẠT ; Cuộc sống
・健康的な生活を送る。
・もう日本の生活に慣れましたか。
・外国での生活は楽しい。
・虫の生活を観察する。
・今月の生活費が足りない。
連: 生活が苦しい ＞＜ 生活が楽だ
合: 生活費 (せいかつひ)

28. 通勤 (つうきん) = THÔNG CẦN ; Đi làm (di chuyển)
・私は毎日2時間もかけて通勤している。
関: 通学 (つうがく)・通院 (つういん)
使い分け: 勤務時間・通勤時間・出勤時間

29. 学歴 (がくれき) = HỌC LỊCH ; Trình độ học vấn, bằng cấp
・学歴が高くても、実力があるかどうかわからない。
・子供にいい学歴をつけさせたいと思う親が多い。
・学歴をつける／実力をつける
合: 高学歴 (こうがくれき)

30. 給料 (きゅうりょう) = CẤP LIỆU ; Lương
・会社から給料をもらう。
・今日は給料日だ！
合: 給料日 (きゅうりょうび)

## 31–40

合: 面接試験 (めんせつしけん)

33. 観光 (かんこう) = QUAN QUANG ; Du lịch, tham quan
・来日の目的は観光です。
・先週、ダラットを観光して回った。
合: ［地名］＋観光

34. 帰国 (きこく) = QUY QUỐC ; Về nước
・今度の正月には帰国するつもりだ。

35. 帰省 (きせい) = QUY TỈNH ; Về quê
・お盆には故郷に帰省する日本人が多い。

36. 帰宅 (きたく) = QUY TRẠCH ; Về nhà
・毎日忙しくて帰宅が遅い。

37. 参加 (さんか) = THAM GIA ; Tham gia
・ボランティア活動に参加する。
合: 参加者 (さんかしゃ)
対: 不参加 (ふさんか)

38. 出席 (しゅっせき) = XUẤT TỊCH ; Có mặt
対: 欠席 (けっせき)
関: 退職届 (たいしょくとどけ)

39. 欠席 (けっせき) = KHUYẾT TỊCH ; Vắng mặt
合: 欠席届 (けっせきとどけ)
対: 出席 (しゅっせき)

40. 遅刻 (ちこく) = TRÌ KHẮC ; Đến muộn
・寝坊して会社に遅刻する。
・面接では1分の遅刻も許されない。

## 41–50
41. 化粧 (けしょう) = HOÁ TRANG ; Trang điểm
・あなたは毎日、お化粧に何分ぐらいかけていますか。
連: 化粧が薄い ＞＜ 化粧が濃い
連: 化粧を落とす
合: 化粧品 (けしょうひん)
関: 口紅 (くちべに)
使い分け: メイク (hay dùng trong hội thoại hằng ngày) ＝ 化粧

42. 計算 (けいさん) = KẾ TOÁN ; Tính toán
・私は計算が苦手だ。
・旅行にいくらかかるか計算する。

43. 計画 (けいかく) = KẾ HOẠCH ; Lên kế hoạch
・来年の計画を立てる。
・夏休みには富士山に登ろうと計画している。
使い分け: プラン hay dùng trong kinh doanh

44. 成功 (せいこう) = THÀNH CÔNG ; Thành công
・失敗は成功の元
合: 大成功 (だいせいこう)
対: 失敗 (しっぱい)

45. 失敗 (しっぱい) = THẤT BẠI ; Thất bại
・失敗は成功の元
対: 成功 (せいこう)

46. 準備 (じゅんび) = CHUẨN BỊ ; Chuẩn bị
・引越しの準備が終わった。
・会議の資料を準備する。
使い分け: 用意 (ようい) = đồ vật cụ thể, ví dụ 車を用意しました
使い分け: 準備 = đồ vật cụ thể lẫn tinh thần, phạm vi rộng, ví dụ 心の準備が必要
使い分け: Độ khẩn cấp 用意 ＞ 準備

47. 整理 (せいり) = CHỈNH LÝ ; Sắp xếp
・資料を整理する。
・もの／資料／頭を整理する。

48. 注文 (ちゅうもん) = CHÚ VĂN ; Đặt hàng/ Gọi món
・書店・アマゾンで本を注文する。
・喫茶店でコーヒーを注文する。
連: 注文をとる
連: 注文の品が届く

49. 貯金 (ちょきん) = TRỮ KIM ; Tích tiền
・銀行にボーナスを貯金する。
連: 貯金を引き出す・貯金を下ろす

50. 徹夜 (てつや) = TRIỆT DẠ ; Thức đêm
・徹夜で仕事する／勉強する。

## 51–60
51. 引っ越し (ひっこし) = DẪN VIỆT ; Chuyển nhà
・引越しの準備が終わった。
・引越しを手伝う。
・東京からハノイに引越しする。

52. 身長 (しんちょう) = THÂN TRƯỜNG ; Chiều cao
・身長を測る。
・兄は身長が高い ＞＜ が低い
・身長が伸びる。
使い分け: 身長が高い・低い; 身長が伸びる

53. 体重 (たいじゅう) = THỂ TRỌNG ; Cân nặng
・体重を測る。
・妹の体重は170キロだ。
合: 体重計 (たいじゅうけい)
使い分け: 体重が重い・軽い; 体重が増える・減る

54. けが = Vết thương

連: けがが治る・けがを治す
関: 傷 (きず)・やけど・骨折 (こっせつ)

55. 会 (かい) = HỘI ; Tiệc

合: 忘年会 (ぼうねんかい)・誕生日会 (たんじょうびかい)・新年会 (しんねんかい)

56. 趣味 (しゅみ) = THÚ VỊ ; Sở thích
・趣味は読書です。
・彼女はいつも趣味のいい服を着ている。
連: 趣味がいい ＞＜ 趣味が悪い

57. 興味 (きょうみ) = HƯNG VỊ ; Quan tâm/ Hứng thú
・私は歴史に興味があります。
・小さな子供は何にでも興味を持つ。
連: 興味がある ＞＜ 興味がない
連: 興味を持つ
合: 興味深い (きょうみぶかい)

58. 思い出 (おもいで) = TƯ XUẤT ; Kỷ niệm

・思い出してうれしい。
関: 思い出す (おもいだす)

59. 冗談 (じょうだん) = NHŨNG ĐÀM ; Nói đùa
・冗談を言ったら彼女が本気にした。
使い方: 冗談を言う ○ / 冗談する ✕

60. 目的 (もくてき) = MỤC ĐÍCH ; Mục đích
・来日の目的は観光です。
合: 目的地 (もくてきち)

## 61–70

・再会を約束して別れた。

64. 我慢 (がまん) = NGÃ MẠN ; Chịu đựng

68. 賛成 (さんせい) = TÁN THÀNH ; Tán thành

69. 反対 (はんたい) = PHẢN ĐỐI ; Phản đối

合: 反対側 ＞＜ 賛成側

・10年後に私がどうなっているか、全然想像がつかない。
・豊かな想像力が欲しいなあ。
合: 想像力 (そうぞうりょく)
